# Обновлённые файлы трафаретов GraFiS

В этом пакете **переписаны сами 32 файла `.vss`**. Исправленный VBA уже находится внутри них. Переносить код через редактор VBA или запускать `apply-visio-fixes.ps1` не требуется.

## Установка

1. Закройте Visio. Сохраните резервную копию существующей папки GraFiS.
2. Распакуйте содержимое этого архива **в существующую папку скачанного репозитория**, согласившись заменить одноимённые файлы. Папки со справочником, изображениями и другими ресурсами должны остаться на своих местах. Это пакет замены файлов, а не полная копия всех ресурсов репозитория.
3. В этой папке дважды щёлкните `Install-GraFiS.cmd`. Установка выполняется один раз: она создаёт ярлык `GraFiS` на рабочем столе и добавляет именно эту папку в доверенные расположения Visio для текущего пользователя. Подпапки автоматически доверенными не становятся. Корпоративные ограничения могут запретить использование доверенных расположений.
4. Открывайте схемы через ярлык `GraFiS` или `Start-GraFiS.cmd`. В окне выбора можно выделить несколько схем. Трафареты подключаются из этой папки к панели «Фигуры». Не выделяйте все `.vss` в Проводнике для одновременного открытия.

Используйте отдельную локальную папку библиотеки, например `C:\GraFiS`, а не корень диска, общую папку «Загрузки» или сетевой ресурс. Не перемещайте её после установки без повторного запуска установщика.

## Что изменено

- Код 169 модулей перенесён непосредственно внутрь 32 трафаретов. В каждом проекте добавлены вспомогательный модуль и контроллер работы с документами.
- Подготовка рисунка проверяет тип активного документа; переключение между схемами обрабатывается отдельно для каждого рисунка.
- Уже загруженный обновлённый трафарет подключает центральный трафарет, который загружает остальные файлы библиотеки из той же папки.
- Трафареты открываются только для чтения, с подключением к панели фигур. Отдельные окна скрываются после проверки подключения.
- Служебные изменения read-only трафаретов не требуют записи на диск. Для рабочих схем и трафаретов, намеренно открытых для редактирования, запросы сохранения остаются включёнными.
- Запуск через ярлык не восстанавливает сохранённый в старой схеме набор отдельных окон и старые пути к трафаретам. Файл схемы на диске при открытии не перезаписывается.

Если открывать схему обычным двойным щелчком, Visio может снова восстановить сохранённые в ней старые пути и окна. Ярлык GraFiS обеспечивает загрузку библиотеки из текущей папки без зависимости от этих путей. Ассоциации файлов Windows установщик не меняет.

## Что проверено

Из полученных `.vss` повторно извлечены все 535 встроенных модулей. Тексты изменённых модулей сверены с исходниками; данные фигур, мастеров, стилей, форм и остальные доступные блоки документа сверены с оригиналами. Проверены контейнеры CFB, таблицы размещения потоков, сжатый VBA, перечни модулей и контрольные суммы файлов. Старые кэши скомпилированного VBA отключены согласно MS-OVBA; при загрузке Visio должен компилировать актуальные исходники.

**Windows/Visio в среде подготовки отсутствуют. Компиляция и исполнение VBA, работа COM-запуска, окон и диалогов в самом Visio не проверены. Этот пакет содержит реальные изменённые файлы, но не является подтверждением отсутствия всех ошибок.** Сначала откройте копии двух схем и проверьте свои обычные операции до использования на оригиналах.

В `binary-rewrite-report.json` указаны контрольные суммы оригиналов и изменённых файлов. Инструменты воспроизводимой записи находятся в `tools/rewrite-vss.py` и `tools/compound_writer.py`.

## GitHub

При добавлении в репозиторий замените именно файлы `.vss` из этого архива и добавьте остальные файлы пакета. В изменениях Git должны появиться 32 бинарных `.vss`. Одна загрузка папки `_codes` не обновляет трафареты.

## Откат

Закройте Visio и восстановите папку из резервной копии. Ярлык GraFiS можно удалить. Добавленное доверенное расположение можно убрать в параметрах Visio: «Центр управления безопасностью» → «Параметры центра управления безопасностью» → «Надёжные расположения» (название зависит от локализации).
