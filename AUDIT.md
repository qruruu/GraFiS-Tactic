# Обзор кода и исправления

Дата: 12.10.2026. База: `a2cce2c9f369426f283c6c6db17ba9c828f60f01`.

## Дополнение версии 2

Проверены обработчики открытия всех 32 корневых трафаретов с VBA. Введены проверка типа активного документа, отложенная инициализация рисунка и контроллер подключения трафаретов к панели фигур. Read-only трафареты очищают признак изменений в памяти; редактируемые трафареты и рисунки сохраняют обычное поведение сохранения. Подробности и ограничения — в README-STENCIL-FIX.md. Статическая проверка охватывает 554 исходных модуля; нативная компиляция и проверка окон/диалогов Visio не выполнены.

## Объём и метод

Получены исходники репозитория и 37 бинарных `.vss`. Из контейнера `VisioDocument` восстановлены сжатые фрагменты встроенного VBA; извлечено 473 модуля. Код не исполнялся при извлечении. Сверка подозрительных участков «Линии», «Очаг» и «ПТВ» подтвердила совпадение текстовых исходников со встроенным VBA, за исключением экспортных заголовков. Найденные различия и отсутствующие модули учтены в манифесте применения.

По всему доступному текстовому VBA проведена инвентаризация и статическое сканирование: глобальные события, выбор активной страницы/документа, работа с ID, отключение событий, обработка ошибок, файловые номера, объявления API, зависимости процедур. Детально прослежены обработчики и вызываемые ими функции импорта данных, закрытие проектов, операции обращения фигур и новый агент ИИ. Это не заменяет ручной разбор каждой математической формулы и выполнение всех ветвей в Visio.

До исправлений в основном `_codes` было 482 модуля, около 3,1 МБ исходников. Найдено 463 упоминания `ActivePage`, 204 `ActiveDocument`, 34 использования `EventsEnabled`, 192 строки подавления ошибок. Эти числа — ориентиры для обзора, а не число ошибок: работа с активным окном допустима для многих пользовательских команд.

## Проверки

- Выполнены статические проверки согласованности 501 модуля после исправлений: наличие одинаковых вспомогательных модулей, сигнатуры обёрток, отсутствие повторных определений процедур, передача контекста фигуры, заголовки модулей.
- Проверен `git diff --check` с учётом существующих CRLF-окончаний VBA.
- Пакет содержит ожидаемые хеши тел оригинальных встроенных модулей и исправленных модулей. Скрипт проверяет оригиналы до записи и считывает код после замены.
- Подготовлены нативные VBA-тесты: одинаковые ID в двух документах, изоляция обновлений и времени, повторный вход, очистка ключей, отсутствие мастера и восстановление состояний событий.
- **Не выполнены**: компиляция VBA, выполнение нативных тестов, запуск PowerShell COM-скрипта на Windows, проверка падения Visio и расчётов на эталонных схемах. В среде нет установленного Visio/Windows.

## Оставшиеся области проверки

1. Общие панели и одинаковые подписи кнопок у обычных/НРС-трафаретов: нужен проверенный механизм владения кнопками и маршрутизации нажатий для одновременной загрузки вариантов. Пакет улучшает очистку, но не переписывает UI-архитектуру.
2. Старые операции соединения/обращения используют выделение активного окна. Для фоновых страниц такие события теперь пропускаются. Для полной фоновой работы нужны объектные версии всех операций.
3. Долгоживущие модели, формы и `DoEvents` в расчётах: требуется проверка закрытия рисунка во время вычислений и переключения страницы. Пакет не переписывает все моделирующие классы.
4. Поставщики ADODB/DAO, доступность Access Database Engine, контролы форм и ссылки VBA: зависят от версии/разрядности установленного Office. Нужна диагностика на целевой машине.
5. ShapeSheet, сжатая геометрия и формулы гидравлических/пожарных расчётов: статическое чтение экспорта не даёт гарантии правильности. Нужны реальные схемы с ожидаемыми результатами.
6. Разбор YAML и отдельные геометрические функции всё ещё содержат подавление ошибок и предположения о структуре данных. Undo scope откатывает исключения, которые дошли до верхнего обработчика, но не превращает все подавленные ошибки в исключения.
7. `Log.txt` не охватывает каждый необработанный сбой, а авария самого процесса Visio может не попасть в VBA-журнал. Нужны текст ошибки и сведения из Windows.

Обещание «все ошибки исправлены» этот пакет не делает. Это конкретный набор исправлений подтверждённых дефектов, подготовленный для компиляции и проверки в целевом Visio.
