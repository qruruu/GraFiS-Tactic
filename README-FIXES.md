# Исправления ГраФиС для нескольких документов

Основа: `qruruu/GraFiS-Tactic`, ветка `master`, коммит `a2cce2c9f369426f283c6c6db17ba9c828f60f01` от 23.09.2026.

Это **пакет исходников и применения исправлений**, а не проверенная сборка `.vss`. Готовые трафареты создаёт установленный Microsoft Visio на Windows. Исходная библиотека не изменяется. Компиляция VBA и тесты внутри Visio в этой среде не выполнялись.

Версия 2 также исправляет инициализацию, отдельные окна и запросы сохранения read-only трафаретов в 32 проектах. Начните с [README-STENCIL-FIX.md](README-STENCIL-FIX.md).

## Что исправлено

- В обработчиках изменения ячеек передаётся объект исходной фигуры, а не только её ID на активной странице. Старые вызовы функций по ID остаются совместимыми.
- Защита от повторного входа учитывает документ, страницу, фигуру и ячейку; зависимые события других ячеек продолжают обрабатываться.
- События мастеров/трафаретов исключены из обработчиков данных рисунка. Обработчики, использующие выделение, не обращают фигуры из фоновой страницы.
- Временные свойства создаются в документе исходной фигуры, в том числе во втором рисунке с уже открытым общим трафаретом.
- ID фигур, которые присваивались переменным `Integer`, переведены в `Long`.
- Процедуры, отключающие события, восстанавливают исходный глобальный `EventsEnabled` при выходе и ошибке.
- При закрытии сначала отключаются подписки, а отсутствие уже удалённой панели не обрывает очистку. Обновление иконок проверяет, что объект кнопок создан.
- Журнал сохраняет исходную информацию об ошибке, использует `FreeFile` и не вызывает новую ошибку, если запись недоступна.
- Исправлены формат списка гидроэлеватора и проверка `User.IndexPers` для соединения фигур ГраФиС.
- В «ИИ»: восстановление событий, отмена пакета изменений при исключении, явная ошибка при отсутствии мастера, работа выделения/Z-порядка с заданной страницей, остановка инструментов после переключения документа/страницы, защита от повторного запуска запроса, удаление обязательной записи на `G:\temp`, отмена HTTP-запроса по тайм-ауту, исправление проверки пустого реестра инструментов.

## Применение к отдельной копии

1. Распакуйте пакет. Закройте Visio, чтобы исключить использование трафаретов во время копирования.
2. Укажите папку установленной библиотеки ГраФиС, в которой лежат `.vss`, `Bitmaps` и справочник. Для результата выберите **новую отдельную папку** вне исходной.
3. В обычном PowerShell Windows выполните из папки пакета:

```powershell
.\tools\apply-visio-fixes.ps1 -SourceDirectory 'C:\GraFiS' -OutputDirectory 'C:\GraFiS-fixed'
```

Пути выше — примеры: замените их на свои. Скрипт использует отдельный `Visio.InvisibleApp`, читает исходники со скрытыми отключёнными макросами, проверяет версии модулей, копирует папку и меняет только копии. Классы и формы сохраняют существующие дизайнеры и свойства; добавляются стандартный модуль `m_GFSSafety` и класс `c_GFSStencilSession`. После записи код считывается обратно и сравнивается с пакетом.

Если установленная версия отличается, скрипт остановится **до создания копии**. Не отключайте проверку хешей: нужен пакет под конкретную версию. Трафареты, отсутствующие в установленной библиотеке, пропускаются. Список реально обработанных файлов выводится в консоль.

Если доступ к `VBProject` запрещён настройками доверия или проект запаролен, автоматический импорт не состоится. Скрипт не меняет настройки безопасности и не снимает пароль. Альтернатива — замена кода модулей вручную через редактор VBA в копиях трафаретов. Вставляйте тело после строк `Attribute`, не импортируйте `ThisDocument` как новый класс. Пустой стандартный модуль `m_GFSSafety` добавляется один раз в каждый затронутый проект.

При ошибке после копирования папка результата может быть неполной; скрипт сообщает это. Не используйте такую копию. Оригинал остаётся без изменений.

## Обязательная проверка в Visio

1. Откройте копии трафаретов в Visio. В редакторе VBA выполните **Debug → Compile** для каждого изменённого проекта. Проверьте **Tools → References**: не должно быть `MISSING`. Формы, COM-контролы и провайдер базы зависят от установленной версии и разрядности Office.
2. В новом временном рисунке импортируйте `tests/GFS_ContextTests.bas` и любой `m_GFSSafety.bas` из пакета. Запустите `RunContextTests`. Тест создаёт два своих несохранённых документа и закрывает их; при успехе в Immediate появляется `PASS`.
3. В копии проекта «ИИ» импортируйте `tests/GFS_YamlFailureTests.bas`. Выберите временный рисунок и запустите `RunYamlFailureTests`. Проверяются ошибочный мастер и восстановление исходного состояния событий. Тест не обращается к LLM.
4. Откройте два **копированных** рабочих рисунка. Меняйте модели/характеристики рукавов, стволов, водоисточников и ГДЗС. Убедитесь, что второй документ не изменяется. Проверьте несколько страниц одного документа, копирование групп и перетаскивание фигур.
5. Поочерёдно закрывайте документы и трафареты; оставшийся рисунок должен продолжать работать. Проверьте открытие ещё одного документа без перезапуска Visio.
6. Если используете «ИИ», во время ожидания ответа переключите рисунок. Запрос должен завершиться сообщением о смене документа до запуска инструментов. Повторите запрос на нужной странице. Проверьте ошибочную модель и последующую работу обычных инструментов.
7. Проверьте расчёты на своих эталонных схемах и сравните результаты с исходной библиотекой. Формулы пожарной модели и гидравлики не объявляются проверенными этим пакетом.

## Что остаётся неподтверждённым

- Отсутствие всех ошибок во всех сценариях: выполнены статический обзор и конкретные исправления, но не полная проверка бизнес-логики и интерфейса.
- Причина конкретного аварийного завершения Visio: для неё нужны сообщение об ошибке, `Log.txt` и версия/разрядность Visio.
- Одновременная работа обычных и НРС-вариантов трафаретов с общей панелью: владение кнопками всё ещё общее; проверяйте комбинацию, которую используете.
- Фоновые соединения: старые операции, основанные на выделении активного окна, теперь пропускаются для фоновых страниц; требуется отдельная переработка этих операций для полностью фонового режима.
- Начальная загрузка трафарета без открытого рисунка и глобальные модели/немодальные формы, хранящие ссылки на страницу, требуют проверки в Visio.
- VBA извлечён из 37 `.vss` (473 модуля). VBA четырёх расчётных трафаретов отсутствует; их ShapeSheet-формулы и бинарная геометрия не компилировались и не пересчитывались.

Подробности и границы обзора — в `AUDIT.md`. Модули, отсутствующие во встроенных проектах, отмечены в `manifest.json` как `source_only` и не применяются автоматически.
